# AP optimization proposal retired

On 25 September 2026 the user withdrew AP-specific optimization. Do not implement
AP surrogates, ranking replay, AP-selected checkpoints, AP-driven search or tuned
ensemble mixtures from earlier proposals. Historical reports keep their true
objectives and selectors; the earlier proposal is available in Git history.

The research objective is information useful for crystallization prediction.
AP3/AP6 remain diagnostic metrics alongside predictive log loss, Brier/calibration,
matched frozen probes and input baselines, present-information retention,
0.75 ps stability, embedding spectra and normalized noise response.

Use the [training-branch policy](training_branches.md) and the
[likelihood-based supervised protocol](../../experiments/supervised_information_20260925/README.md).
