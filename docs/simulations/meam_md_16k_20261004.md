# Periodic 16k-atom CPU/GPU MEAM crystallization comparison

User requested200ps on GPU PyTorch and original CPU LAMMPS and selected450K.
The [recipe](../../configs/simulation/meam_md_16k_20261004.json) creates one new
16,384-atom periodic liquid ancestor using the exact Lee2003 potential, then
runs matched float64 BAOAB paths with identical starting coordinates, velocities
and PCG64 thermostat noise. A separate1ps NVE gate checks energy conservation
and early trajectory fidelity before the long trajectories start.

The periodic specialization adds minimum-image geometry, spatial-bin neighbor
construction and compiled force evaluation to the validated open-cell port.
It remains specific to the pinned pure-Al potential and orthorhombic cells.
Native LAMMPS throughput is measured separately from the external CPU driver
used to control the integrator/noise. See [metric definitions](../metrics/meam_md.md).

Use conda `pointnet-torch214`, with MPI-enabled LAMMPS and mpi4py. Preparation
uses8CPU ranks in the current allocation. Launch freezes source and metrics,
submits an8-core CPU job and detaches a GPU worker in the current allocation.
Each worker profiles its engine and runs the NVE control; both require the
joint numerical gate before starting200ps. Each completion updates the report.

```bash
OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 OVITO_THREAD_COUNT=1 \
python -m src.research.meam_md.prepare --config configs/simulation/meam_md_16k_20261004.json
python -m src.research.meam_md.workflow launch --config configs/simulation/meam_md_16k_20261004.json
python -m src.research.meam_md.report --config configs/simulation/meam_md_16k_20261004.json
```

Execution receipts and logs are in `output/meam_md/al16k-450K-200ps-20261004/technical`.
Results appear in the [report](../../output/meam_md/al16k-450K-200ps-20261004/README.md).
Runs use SCRATCH with native-precision checkpoints copied to STORE every1ps
and at early steps. Restart via the same frozen worker/config after verifying
the previous process stopped. Partial metrics never imply a complete200ps run.
Final observations use verified float16 positions, float32 boxes and exact
identity/time arrays at0.1ps; preserve native states for divergence calculations.

Registry ID: `meam-md-al16k-450K-200ps-20261004`. The new melt is one ancestor,
and CPU/GPU/control branches are dependent descendants. No relaxed views,
encoder training, AP selection or new crystal-specific loss are involved.
One pair can diagnose implementation fidelity and observed crystallization;
independent replicas would be needed for a nucleation-rate comparison.
