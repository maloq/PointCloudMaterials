# Paired relaxed structural collection

The October 8 collection admits dynamic relaxed observations only when their exact
unrelaxed originals remain available as source frames or preserved paired
neighborhoods. Original coordinates are retained for identity audit and later
paired analysis; they never enter the encoder, VICReg views or descriptor head.
The user's clarification explicitly adds already-relaxed static Al/Mg/Ta/Zr
inherent configurations as an exception to the paired-original requirement.
Their relaxed status is user-confirmed; generating potentials, minimizers and
unrelaxed counterparts remain unknown. Static sources retain their archived
train-only material ancestry groups. Existing native-unit static patches are
reused; sources absent from that cache receive 256 seeded interior centers.
Static point clouds have no invented periodic box. No new relaxation is run.

`population.csv` counts unique retained source-manifest/frame/center observations
by inherited fitting role and material. These are correlated neighborhoods,
not independent trajectories. Original selection/test roles are retained in each
task and pooled only for diagnostic monitoring; calibration and previously
blocked/diagnostic ancestry are separate. No new split or phase filter is made.

The shared relaxation index supplies convergence, potential, recipe and file
checksums. Removed/unavailable relaxation products are not regenerated. Retained
native/fixed derived pairs are admitted only when their verified relaxed archive
is still present. Duplicate observations prefer pre-quantization float32 patches,
then float32 patches extracted historically from quantized float16 full cells;
stable producer IDs break ties. Different cache copies or alternative minima do
not multiply the source/frame/center count. Precision is recorded per shard.

For full cells without eligible cached patches, 256 centers are sampled once per
source and reused across every included frame. Nearest80 membership is chosen
in the unrelaxed original and preserved in the relaxed counterpart. The Ni birth
window cohort is explicitly event-centered: all 6,571 planned frames from the
70-birth campaign, not an outcome-blind sample of liquid. All original frames
and exact relaxation receipts must pass checks; partial campaign completion
cannot silently reduce this population. Native Ni float64 restarts are read on
CPU with no force evaluation or additional relaxation.

Targets reuse the previous Small eSEN's exact 198 named outputs, implementation,
fixed material scaling, native alpha backend and safe alpha precision. Targets
are calculated on relaxed coordinates. Means, variances and active masks are
recomputed using training ancestors only. The descriptor objective assigns one
third to each of BO, CNA and TDA; TDA splits its weight equally across 18 blocks
and their active columns. Empty target blocks fail, rather than changing the
objective silently. The local preparation audit compares representative paired
and static inputs against the existing GUDHI target implementation for every
input format and material. Static held-out performance is not established by
the existing Al/Ni monitoring panels.

Scientific training metrics retain the definitions in `spatial_architecture.md`.
The architecture, VICReg, optimizer, BF16 neural precision, batch256, 12 full
epochs, one-epoch warmup and .001-to-.00001 cosine schedule are unchanged.
Epoch length is recomputed from this collection's training count. The final
epoch remains the fixed checkpoint; held-out diagnostics never select it.
