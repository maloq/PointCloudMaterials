# Synthetic hardware benchmark

Start with `RESULTS.md` for the final table with hardware and workload details. `tables/summary.csv` provides full-precision rows; `tables/hardware.csv` and `tables/METRICS.md` retain detailed metrics and exact definitions. `technical/results.json` retains status, raw timings, hardware/software metadata and checks. `technical/config.json` records all workload sizes and launch settings. No datasets or checkpoints are used.
