# Local predictability: consolidated results

The [full report](RESULTS.md) combines completed H100/RTX6000 descriptor, native
onset, observability, physical-prediction and topology studies with the earlier
H200 summaries and historical controls. Evidence captured 17 September 2026,
19:03 UTC (21:03 CEST). One seed for the new local studies.

Main finding: useful predictive information is accessible in physical descriptors,
especially with broader context, but the tested native encoders do not yet retain
or use it as effectively. GATr does not improve physical forecasting at this budget.

Recreate the numerical tables and figures in a fresh directory, without training:

```bash
conda run -n pointnet python -m src.research.local_predictability.report \
  --config configs/analysis/local_predictability_report.json \
  --output output/local_predictability/NEW-SUMMARY
```
